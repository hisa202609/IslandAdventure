## 概要

Unityの教材を基に、C#でゲームの基本的な仕組みを学びながら制作した見下ろし型2Dアクションゲームです。プレイヤーの移動・攻撃、敵との戦闘、鍵や扉を利用した探索などを実装しました。

| 項目 | 内容 |
| --- | --- |
| ジャンル | 見下ろし型2Dアクション・アドベンチャー |
| 制作背景 | 職業訓練の制作課題 |
| 制作期間 | 2週間（2026年10月） |
| 制作人数 | 1人（個人制作） |
| 担当範囲 | Unity上での構築・C#の実装・動作確認・不具合修正 |
| ゲームエンジン | Unity 6（6000.3.24f1） |
| 使用言語 | C# |

> **制作上の位置付け**：教材・講師の参考プロジェクトをベースにした学習制作です。以下では、自身の作業として確認できた実装・調整を中心に紹介します。教材・参考実装の仕様と独自の追加機能を区別するため、確認できていない項目は断定していません。

## 遊び方

キャラクターを操作してマップを探索し、敵と戦いながらアイテムを集めます。鍵を持った状態で対応する扉に接触すると、鍵を消費して扉を開けられます。

| --- | --- |

| 剣による攻撃 | 剣に割り当てたアクション（参考プロジェクトでは `Jump`） |

## 技術的なポイント

### 1. 弓と剣の攻撃処理を分離し、コルーチンで制御

`PlayerAttack.cs` では弓矢と剣の攻撃を別処理として扱い、剣の攻撃時にはエフェクトを生成します。コルーチンを利用して一定時間後にエフェクトを消去し、攻撃が終了したことを管理する変数をリセットします。

```csharp
// 剣の攻撃エフェクトを一定時間後に消去する処理（制作コードより抜粋）
IEnumerator SwordAttack(GameObject swordEffectObj)
{
    yield return new WaitForSeconds(0.3f);
    Destroy(swordEffectObj);
    _swordAttackCoroutine = null;
    _bowObj.SetActive(true);
}
```

- 攻撃処理中かどうかを `Coroutine` 型の変数で把握
- 剣の攻撃中は弓の表示を切り替え、攻撃同士の競合を抑制
- プレイヤーの向きに合わせ、`Quaternion.Euler` により斬撃エフェクトの角度を設定

※ コード例は学習時に確認した実装を基にしています。最終提出版との一致はアップロード前に確認してください。

### 2. 鍵の所持判定と扉・UIの連携

`Door.cs` では、プレイヤーとの衝突を検知し、鍵の所持数が1以上なら鍵を消費して扉を開けます。アイテム情報の変更だけでなく、`UIController` のメソッドを呼び出して表示にも反映させています。

```csharp
// Door.cs の処理を要約した例
if (collision.gameObject.CompareTag("Player") && ItemKeeper.hasKeys >= 1)
{
    ItemKeeper.hasKeys -= 1;
    _uiCnt.UpdateItemCount(ItemType.key, ItemKeeper.hasKeys);
    Destroy(gameObject);
}
```

この処理では、**ゲーム内の所持データ → UIへの反映 → オブジェクトの状態変更**を一連の流れとして扱っています。

### 3. 敵の方向計算と索敵

`EnemyController.cs` ではプレイヤーの位置をもとに移動方向を求め、`Mathf.Atan2` を使って敵の向きを計算します。索敵距離や速度をシリアライズされたフィールドで調整できる構成です。

### 4. Unity Input System の利用

`PlayerInput` と `InputAction` のコールバックを利用し、弓と剣で異なる入力イベントを受け取ります。入力の開始時と終了時のイベントを使い分けることで、単発攻撃と長押しを扱う処理を学びました。

## 苦労した点と解決方法

| 困ったこと | 原因・確認したこと | 対処 |
| --- | --- | --- |
| 矢が想定どおりに飛ばない | 衝突判定・レイヤー設定を確認 | レイヤー設定を修正して正常に動作するようにした |
| 鍵付き扉が反応しない | `OnTriggerEnter2D` と `OnCollisionEnter2D` の違いを確認 | 使用しているColliderの設定に合わせ、衝突イベントを変更 |
| 剣の攻撃処理で不具合が発生 | コルーチンと攻撃状態の管理を確認 | 攻撃中フラグに相当するコルーチン参照の扱いを修正し、正常動作を確認 |
| Git管理時に一時ファイルが問題になる | Unityが自動生成する `Temp` / `Library` なども管理対象になっていた | `.gitignore` を修正し、不要な生成ファイルを除外 |
